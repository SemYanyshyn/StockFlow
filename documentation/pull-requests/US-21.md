# US-21: replace invoice placeholder with list, filters and read-only details

The Invoices menu now loads PostgreSQL stock_movements for both roles. It supports
literal, case-insensitive number search, combined type/warehouse/date filters,
clearing filters and read-only details including supplier and note. The end date
includes the entire selected day. Empty database, no matches and database failure
have distinct Ukrainian messages. Existing navigation and Theme.xaml are retained.

This branch includes only the read path. It does not duplicate the writer/service
from PR #140/#146 or include an inactive creation form. Creation stays disabled
for Employee and hidden for Admin pending the real stock module. The original
feature/se-8-invoices commit 937b10b is preserved separately.
